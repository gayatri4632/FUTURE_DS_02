# 📁 Data Folder

This folder contains the dataset used for Customer Retention & Churn Analysis (Task 2).

## 📊 Description
The dataset includes customer demographic details, subscription information, and churn status used to analyze customer behavior.

## 🎯 Purpose
This data is used to identify:
- Customer churn patterns
- Retention trends
- Impact of contract type, tenure, and internet service on churn

## 🛠 Usage
The dataset is processed in Microsoft Excel using:
- Pivot Tables
- Charts
- Dashboard creation

## 📌 Outcome
This data helps in understanding key drivers of customer churn and improving retention strategies.
