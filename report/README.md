# 📊 Customer Retention & Churn Analysis – Report

## 🎯 Objective
To analyze customer churn behavior and identify patterns that lead to customer attrition in a subscription-based business.

---

## 📁 Dataset Used
Telco Customer Churn Dataset

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts (Bar, Column)
- Data Analysis Techniques

---

## 📊 Analysis Performed

- Overall churn rate analysis
- Contract type vs churn analysis
- Internet service vs churn analysis
- Customer tenure vs churn analysis

---

## 🔍 Key Insights

- Month-to-month contract customers have the highest churn rate.
- Fiber optic users show higher churn compared to DSL users.
- New customers are more likely to churn than long-term customers.
- Customer retention improves significantly with longer contracts.

---

## 💡 Business Recommendations

- Encourage long-term contracts through discounts and offers.
- Improve Fiber optic service quality or pricing strategy.
- Focus on onboarding experience to retain new customers.
- Implement loyalty programs for long-term customers.

---

## 📈 Conclusion
This analysis helps understand customer behavior and provides actionable insights to reduce churn and improve retention strategies in a subscription-based business.
